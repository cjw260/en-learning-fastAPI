# P04：核心业务 API 迁移

状态：`NOT_STARTED`

## 启动条件

P03 完成并推送；新的执行重新加载 skill 和 framework parity；阶段锁为 P04。

## 目标与外部效果

FastAPI 提供用户、词库、课程、学习和埋点 API；前端路径与主要数据形状保持兼容，同时完成密码、身份、上传和输入验证安全修复。

## 实现步骤

1. 实现 access/refresh JWT 依赖、token 类型/过期检查和当前用户解析。
2. 注册时安全哈希密码；登录常量时间校验；刷新时确认用户存在并按策略轮换 token。
3. 迁移用户资料和头像上传，增加鉴权、MIME/内容/大小、对象键和失败清理。
4. 迁移课程列表/我的课程，保持图片 URL 与两位小数价格序列化。
5. 迁移 WordBook 搜索、八类标签、分页和 `frq` 数值稳定排序。
6. 迁移课程学习与掌握记录，用数据库事务、唯一约束/upsert 和真实新增数更新 wordNumber。
7. 迁移 tracker 六类端点，增加运行时 schema、长度/大小/速率限制和隐私过滤。
8. 为每条路由建立成功、422/400、401、403、404、409 和依赖失败契约测试。

## 验收标准

- [ ] 所有既有 Core 非支付路由都有契约清单和测试。
- [ ] 密码不明文存储/返回；JWT 伪造、类型错误、过期和越权被拒绝。
- [ ] 上传必须认证，危险/超限文件不能进入公开 bucket。
- [ ] course price/null/date/envelope 与批准基线兼容。
- [ ] WordBook 过滤、分页和 `frq` 排序稳定正确。
- [ ] 学习记录重复/并发不重复计数，未购买课程被拒绝。
- [ ] tracker 错误和超大载荷可控，日志无敏感数据。
- [ ] 未实现支付、Socket.IO 或 worker。

## 回退

将 `/api/` upstream 指回 NestJS；安全 schema/密码差异必须在切流前有兼容说明。
