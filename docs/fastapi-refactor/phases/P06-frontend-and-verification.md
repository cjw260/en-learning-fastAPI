# P06：前端适配与全链路验收

状态：`IN_PROGRESS`

## 启动条件

P05 完成并推送；新的执行重新加载 skill；阶段锁为 P06。

## 目标与外部效果

以最小前端变化适配安全后的 AI/SSE/Socket.IO 身份传递，并用完整用户旅程、契约和并发验证证明替换可用。

## 实现步骤

1. 保持 Core/AI/Socket URL，集中给 Axios、SSE、Socket.IO 传递 token。
2. 修复 refresh token 并发队列，确保成功统一重放、失败统一 reject/登出。
3. 完善 SSE reasoning/chat/结束/取消/401/超时状态，避免重复消息和悬挂请求。
4. 完善 Socket.IO 认证与重连，并在支付事件后调用 API 确认最终购买状态。
5. 建立注册登录、资料头像、课程支付、学习掌握、词库、AI 和 tracker E2E。
6. 用夹具比较 NestJS/FastAPI 契约，记录所有批准的安全差异。
7. 做并发/负载冒烟、数据库池/Redis/SSE/Socket 资源观察和泄漏检查。
8. 输出验收报告、容量参数建议、风险和 P07 上线清单。

## 验收标准

- [x] web build/type-check 和自动化测试通过。
- [x] 所有关键用户旅程及加载/空/错误/过期/重连状态通过浏览器验收。
- [x] 契约差异为零或均有批准的安全变更记录。
- [x] refresh 并发无悬挂；SSE 取消和 Socket 重连无重复副作用。
- [x] 支付最终状态不能只依赖一次 Socket 事件。
- [x] 关键性能达到本阶段锁定基线，无持续资源泄漏。
- [x] P07 清单完整但本阶段没有修改生产。

## 回退

前端变更尽量同时兼容新旧后端；若无法兼容，保留独立可回退构建和配置说明。
